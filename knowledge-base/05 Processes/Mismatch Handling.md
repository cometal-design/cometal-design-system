# Обработка расхождений

1. Зафиксировать источник, узел и наблюдаемое расхождение.
2. Не исправлять смысл молча и не выбирать источник по собственному предположению.
3. Поставить компоненту статус `blocked`.
4. Показать проблему Design System Lead и предложить варианты.
5. После решения обновить все затронутые источники.
6. Повторить проверки совпадения.
7. Снять блокировку только при полном смысловом и визуальном соответствии.
