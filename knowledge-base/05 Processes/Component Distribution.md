# Распространение утверждённого компонента

## Триггер

Design System Lead сообщает, что визуальный компонент в Figma DS Core готов и утверждён для распространения.

## Путь

1. Проверить Figma-компонент и его зависимости.
2. Присвоить стабильный ID и создать запись реестра.
3. Создать или обновить спецификацию компонента.
4. Синхронизировать DTCG-токены.
5. Реализовать React-компонент и публичный API.
6. Добавить Stories, interaction- и accessibility-проверки.
7. Создать или обновить паспорт в Obsidian.
8. Запустить полную локальную проверку.
9. Сравнить все связанные данные между источниками.
10. Передать готовый результат на техническое review Frontend Lead.

Любое расхождение переводит компонент в `blocked` до решения Design System Lead.
