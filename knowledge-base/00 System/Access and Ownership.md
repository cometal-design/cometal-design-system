# Доступы и владение

## Коротко

Система должна пережить смену владельца, компьютера и аккаунта. Поэтому код, документация и история живут в переносимом Git-репозитории, а сервисы подключаются поверх него.

## Где что находится

- Figma — визуальная модель.
- Git specifications/registry — ID, статусы и спецификации.
- Git tokens/React — исполняемая реализация.
- Storybook — живые состояния, проверки и релизы.
- Obsidian — контекст и знания системы.
- GitHub и Vercel — инфраструктура размещения, а не новые источники истины.

## Секреты

В Obsidian и Git не хранятся пароли. Здесь фиксируются только название аккаунта, владелец, ссылка и имя записи в password vault.

Полные правила: [Access and ownership](../../docs/governance/access-and-ownership.md).

Порядок настройки: [Account bootstrap](../../docs/runbooks/account-bootstrap.md).
