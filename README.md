# Cometal Design System

Переносимый репозиторий дизайн-системы Cometal для web-продукта на React.

Репозиторий не привязан к личному GitHub, домену или хостингу. Его можно передать в корпоративный Git с сохранением всей истории.

## Что находится внутри

- `packages/tokens` — DTCG-токены и их сборка в CSS/JavaScript/JSON.
- `packages/react` — типизированная React-библиотека `@cometal/react`.
- `apps/storybook` — документация, состояния и проверки компонентов.
- `specifications` — спецификации компонентов.
- `registry` — ID, статусы, версии и ссылки.
- `knowledge-base` — Obsidian Vault с контекстом, решениями и правилами.
- `scripts` — проверки синхронизации источников истины.

## Быстрый старт

```bash
pnpm install
pnpm dev
```

Полная локальная проверка:

```bash
pnpm validate
```

Команда проверяет связи реестра, типы, unit- и browser-тесты, сборку пакетов и статического Storybook.

## Главное правило

Компонент добавляется в код только после прямого подтверждения Design System Lead, что визуальная модель в DS Core готова. Любое найденное расхождение блокирует продвижение компонента до решения владельца дизайн-системы.
