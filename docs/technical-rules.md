# Технические правила библиотеки

Статус: предварительно утверждены для автономной сборки; совместимость с продуктом подтверждается Frontend Lead перед первым `Beta`-релизом.

## Архитектура

- Один переносимый pnpm monorepo.
- React + TypeScript со строгой типизацией.
- React является peer dependency библиотеки, а не встраивается в пакет.
- Компоненты не зависят от роутера или бизнес-логики продукта.
- Стили поставляются как скомпилированный CSS и используют namespaced CSS variables.
- Токены хранятся в стабильном DTCG JSON-формате.
- Storybook работает через React + Vite.

## Качество

- Семантический HTML прежде ARIA-эмуляции.
- Keyboard и focus behavior входят в спецификацию компонента.
- Accessibility-проверки Storybook блокируют готовность компонента.
- Каждое поддерживаемое состояние имеет Story.
- Интерактивное поведение проверяется в реальном браузере.
- Публичный API минимален и типизирован; случайные визуальные настройки не добавляются как props.

## Переносимость

- В репозитории нет личных имён, абсолютных локальных путей, токенов доступа и паролей.
- Сборка не зависит от конкретного Git-провайдера.
- Публикация пакета и Storybook подключается отдельным инфраструктурным слоем позднее.
- Все секреты должны передаваться через переменные окружения хостинга.
