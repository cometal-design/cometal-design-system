# ADR-0001: переносимый monorepo

- Статус: принято
- Дата: 2026-07-21
- Владелец решения: Design System Lead

## Контекст

Дизайн-система создаётся автономно до подключения корпоративной разработки. Результат не должен принадлежать личному аккаунту и должен переноситься в корпоративный Git без перестройки.

## Решение

Хранить токены, React-библиотеку, Storybook, спецификации, реестр и Obsidian Vault в одном приватном Git-репозитории. Локальная история Git создаётся до появления корпоративного remote.

## Последствия

- Одно изменение может атомарно обновить все затронутые источники.
- Репозиторий передаётся компании целиком вместе с историей и тегами.
- Публикация и защищённый доступ к Storybook не блокируют локальную разработку.
- Личные настройки и секреты исключаются из Git.
