- ID: `template.widget`

## Scope

Widget публикует reusable template shell для table/content surfaces: heading, description, actions и content slot.

## Contract

- Heading block optional
- Actions slot optional
- Content slot required
- Не определяет продуктовую бизнес-логику, только shell composition
