## Scope

Context Menu публикует contextual action surface, включая pointer anchor, keyboard roving focus и size-specific items.

## Contract

- Sizes: `l`, `m`, `s`
- Item tones: `default`, `danger`
- Item states: `default`, `selected`, `disabled`
- Divider size inherits menu size
